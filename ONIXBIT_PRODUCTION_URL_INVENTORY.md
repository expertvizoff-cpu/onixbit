## Что я проверил

Рабочий сайт `onixbit.ru` во время инвентаризации не менялся.

Проверка была только на чтение:

- публичный `robots.txt`;
- публичный `sitemap.xml`;
- публичные страницы через `HEAD`/`GET`;
- локальные файлы маршрутов и данных в репозитории.

Проверенные источники:

- `https://onixbit.ru/robots.txt`
- `https://onixbit.ru/sitemap.xml`
- `https://onixbit.ru/`
- все URL из sitemap;
- `src/app/sitemap.ts`
- `src/app/robots.ts`
- `src/data/site.ts`
- `src/data/articles.ts`
- `src/data/article-extras.ts`

## Краткий вывод

- `robots.txt` разрешает обход сайта и указывает на `https://onixbit.ru/sitemap.xml`.
- В текущем XML sitemap найдено 18 публичных URL.
- Все 18 URL из sitemap ответили HTTP `200` при проверке 2026-07-05.
- Текущая публичная структура сайта: главная, 3 страницы услуг, тарифы, доказательства/сертификаты, статьи, контакты, политика.
- Статьи уже опубликованы и могут накапливать SEO-вес, поэтому их URL лучше не менять.
- `/cases` уже существует, но детальные страницы кейсов пока не опубликованы.
- Будущие страницы `/processy/*` пока не публичные. Добавлять их нужно только после отдельного утверждения.
- Локальные preview-маршруты есть в репозитории, но на текущем проде проверенные preview URL ответили `404`. Их нельзя добавлять в sitemap и публичную навигацию без отдельного решения.
- `/api/health` отвечает `200`, но это технический endpoint, не публичная SEO-страница.
