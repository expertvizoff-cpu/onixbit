# Onixbit Final Logo Package

Last updated: 2026-07-05

This package fixes two approved logo structures:

- `lockup` — separate sign plus full wordmark `ОНИКСБИТ`; recommended as the primary master for the website header, documents, KP, and most external materials.
- `mark-as-o` — the sign replaces the first Cyrillic `О`; recommended as a secondary/accent version when a more compact or more branded word shape is useful.

## Color Modes

- `primary` — red sign, dark `ОНИКС`/`НИКС`, deep-red `БИТ`; use on light backgrounds.
- `inverse-red` — red sign, white `ОНИКС`/`НИКС`, deep-red `БИТ`; use on dark backgrounds when the red accent should remain visible.
- `inverse-white` — all white; use on dark or photo backgrounds when maximum contrast is needed.
- `mono-dark` — all dark; use in restrained documents, monochrome layouts, and where red is not appropriate.

## Files

All PNG files are transparent `444 x 110` RGBA. SVG files contain no visible background rectangle.

## Usage Rule

Use `lockup/primary` as the default master. Use `mark-as-o` only as a deliberate alternate, not mixed randomly with the primary logo on the same surface.
