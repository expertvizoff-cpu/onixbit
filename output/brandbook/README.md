## Logo Rule

Use `lockup/primary` as the default master. Use `mark-as-o` only as a deliberate alternate.

Do not use earlier exploration boards or names such as `26`, `26A`, `ОС`, `ЗН`, `RU-05`, or `BIT-R2` as public logo sources unless the asset is already included in `output/logos/final/`.

## Color Rule

Primary brand red is `#ED1C24`. Deep red for the `БИТ` part and darker accents is `#B80F17`. Amber `#FFD45A` is a secondary proof/warmth color, not a replacement for the brand red.

## Typography Rule

Use Montserrat for display/headings and Manrope for body/UI copy. Keep letter spacing at `0`.

## Usage Rule

The public site stays mostly light, calm and scannable. Dark, cinematic/HUD language is reserved for process-demo pages where it explains a real business route.
