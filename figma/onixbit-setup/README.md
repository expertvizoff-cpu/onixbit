# Onixbit Figma Setup

Dev plugin for preparing a clean Onixbit redesign Figma file.

## Run

1. Open the target Figma file.
2. Figma menu: `Plugins` -> `Development` -> `Import plugin from manifest...`.
3. Select `figma/onixbit-setup/manifest.json`.
4. Run `Onixbit Figma Setup`.

The plugin creates the working pages, local paint/text styles, a hybrid sitemap board, light-page wireframes, dark process-page wireframes, three key-screen concept frames, desktop and mobile homepage film frames, service/article concept frames, and reusable component boards.

It removes only layers previously generated by this plugin.
