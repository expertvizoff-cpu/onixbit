# Как подключить Codex в VS Code с нуля

Дата инструкции: 26 июня 2026.

Эта инструкция написана максимально простым языком. Представим, что у тебя есть только компьютер, VS Code и желание снова получить помощника, который работает с проектом как сейчас: читает файлы, правит код, запускает команды и объясняет, что делает.

## 0. Важное про Россию, оплату и ограничения

OpenAI официально работает не во всех странах. Россия не входит в список поддерживаемых стран для OpenAI API, и доступ из неподдерживаемой страны может привести к блокировке аккаунта или отказу в обслуживании.

Я не могу давать инструкцию по обходу санкций, региональных блокировок, платежных ограничений, покупке чужих аккаунтов, использованию поддельных данных, виртуальных карт ради обхода правил или VPN-схемам для нарушения условий сервиса. Это рискованно: аккаунт могут заблокировать, деньги можно потерять, а данные проекта могут оказаться у непонятных посредников.

Что можно делать нормально и безопаснее:

1. Использовать личный или рабочий аккаунт OpenAI, если он оформлен в поддерживаемой стране и оплата проходит легально.
2. Использовать корпоративный доступ через компанию, которая имеет право пользоваться OpenAI в своей юрисдикции.
3. Попросить заказчика или работодателя выдать доступ к ChatGPT Team/Business/Enterprise или API-ключу в их рабочей организации.
4. Если официальный доступ невозможен, временно использовать альтернативы: локальные модели, другие провайдеры ИИ, GitHub Copilot, JetBrains AI или внутренние корпоративные инструменты.

Самый устойчивый вариант: официальный ChatGPT Plus/Pro/Business/Edu/Enterprise или официальный OpenAI API-ключ, оформленный без нарушения правил.

## 1. Что именно нужно подключить

Есть два основных способа:

1. Codex в VS Code. Это самый похожий вариант на текущую работу: открываешь проект в VS Code, справа появляется панель Codex, пишешь задачу, Codex читает проект и вносит изменения.
2. Codex CLI. Это версия в терминале. Её удобно использовать, если ты работаешь через командную строку или WSL на Windows.

Для новичка лучше начать с расширения VS Code.

## 2. Что нужно заранее

Проверь, что есть:

1. VS Code.
2. Интернет.
3. Аккаунт ChatGPT/OpenAI с доступом к Codex или API-ключ OpenAI.
4. Git, если ты работаешь с проектами из GitHub.
5. На Windows желательно Windows 11. Windows 10 может работать, но хуже и не всегда стабильно.

Если у тебя Windows и проекты на Next.js/Node.js, удобно поставить:

1. Git for Windows: https://git-scm.com/download/win
2. Node.js LTS: https://nodejs.org/
3. Windows Terminal: https://apps.microsoft.com/detail/9n0dx20hk701

## 3. Вариант А: подключить Codex прямо в VS Code

### Шаг 1. Открой VS Code

Открой программу VS Code.

### Шаг 2. Открой Extensions

Нажми слева иконку Extensions. Она выглядит как четыре квадратика.

Или нажми:

```text
Ctrl+Shift+X
```

### Шаг 3. Найди расширение Codex

В поиске расширений введи:

```text
Codex
```

Ищи официальное расширение OpenAI Codex. Убедись, что издатель связан с OpenAI.

### Шаг 4. Установи расширение

Нажми:

```text
Install
```

После установки в VS Code должна появиться панель Codex. Обычно она находится справа или слева в боковой панели.

### Шаг 5. Войди в аккаунт

Расширение попросит войти одним из способов:

1. Через ChatGPT account.
2. Через OpenAI API key.

Если у тебя есть ChatGPT Plus/Pro/Business/Edu/Enterprise, начинай с входа через ChatGPT account.

Если у тебя есть только API-ключ, выбирай API key.

### Шаг 6. Открой папку проекта

В VS Code нажми:

```text
File -> Open Folder
```

Выбери папку проекта.

Например:

```text
/home/aleksander/projects/onixbit
```

На Windows это может быть что-то вроде:

```text
C:\Users\Ты\Projects\onixbit
```

### Шаг 7. Напиши Codex первую задачу

В панели Codex напиши простую задачу:

```text
Прочитай проект и кратко объясни, как он устроен. Ничего не меняй.
```

Так ты проверишь, что Codex видит файлы и может работать в проекте.

### Шаг 8. Разрешения

Codex может попросить разрешение на команды или доступ к сети.

Обычная логика:

1. Читать файлы проекта можно разрешать.
2. Менять файлы проекта можно разрешать, если ты сам попросил внести изменения.
3. Доступ к интернету разрешай только когда он реально нужен: поставить пакет, проверить документацию, открыть сайт.
4. Полный доступ ко всему компьютеру не включай без необходимости.

## 4. Вариант Б: подключить Codex CLI

Codex CLI нужен, если хочешь запускать помощника из терминала.

### Windows через WSL

На Windows самый надежный вариант для веб-разработки часто такой:

1. Установить WSL.
2. Открыть проект внутри Linux-среды.
3. Запускать VS Code командой `code .`.

Открой PowerShell от имени администратора и выполни:

```powershell
wsl --install
```

Перезагрузи компьютер, если Windows попросит.

Открой WSL:

```powershell
wsl
```

Внутри WSL установи Codex:

```bash
curl -fsSL https://chatgpt.com/codex/install.sh | sh
```

Запусти:

```bash
codex
```

Войди в аккаунт, когда Codex попросит.

### macOS или Linux

Открой терминал и выполни:

```bash
curl -fsSL https://chatgpt.com/codex/install.sh | sh
```

Потом:

```bash
codex
```

## 5. Как входить: ChatGPT или API key

Codex поддерживает два способа входа:

1. ChatGPT account.
2. OpenAI API key.

Разница простая:

1. ChatGPT account подходит для обычной работы в VS Code и Codex Cloud. Лимиты зависят от твоего плана ChatGPT.
2. API key подходит для локальной работы и автоматизации. Деньги списываются по API-тарифам OpenAI.

Если ты не понимаешь, что выбрать, выбирай ChatGPT account.

## 6. Как получить API-ключ

Если API доступен твоему аккаунту:

1. Открой https://platform.openai.com/api-keys
2. Войди в аккаунт.
3. Нажми Create new secret key.
4. Скопируй ключ.
5. Никому его не отправляй и не вставляй в код проекта.

API-ключ выглядит как секретный пароль. Если он утечет, другие люди смогут тратить твои деньги.

## 7. Как правильно просить Codex о работе

Плохой запрос:

```text
Сделай красиво.
```

Хороший запрос:

```text
Открой страницу AboutPage.tsx, улучши адаптивность блока с преимуществами, сохрани текущий стиль сайта, после изменений запусти проверку сборки. Перед правками кратко скажи, какие файлы будешь менять.
```

Еще хороший запрос:

```text
Найди причину ошибки в сборке. Сначала прочитай package.json и ошибку, потом предложи минимальное исправление и внеси его.
```

Если не хочешь, чтобы Codex менял файлы:

```text
Только объясни, ничего не меняй.
```

Если хочешь, чтобы он сам сделал:

```text
Внеси изменения сам и проверь результат.
```

## 8. Как работать безопасно

Перед большой задачей проверь статус Git:

```bash
git status
```

Если Codex изменил файлы, смотри разницу:

```bash
git diff
```

Если изменения хорошие:

```bash
git add .
git commit -m "Описание изменений"
```

Если не уверен, попроси:

```text
Покажи, какие файлы ты изменил и зачем.
```

## 9. Что делать, если Codex не видит проект

Проверь:

1. Ты открыл именно папку проекта, а не один файл.
2. В VS Code выбран правильный workspace.
3. В терминале ты находишься внутри проекта.
4. У тебя есть права на чтение и запись файлов.

Попроси Codex:

```text
Проверь текущую рабочую папку и список файлов проекта.
```

## 10. Что делать, если не получается войти

Попробуй по порядку:

1. Перезапусти VS Code.
2. Выйди из Codex и войди снова.
3. Проверь, что аккаунт ChatGPT открыт в браузере.
4. Попробуй вход через device code, если обычный вход не работает.
5. Если используешь API-ключ, проверь, что он не удален и на аккаунте есть доступ к API.
6. Проверь региональные ограничения. Для России официальный доступ может быть недоступен.

## 11. Что делать, если оплата из России не проходит

Коротко: это ожидаемо. Из-за региональных и платежных ограничений российские карты обычно не подходят для оплаты OpenAI.

Безопасные варианты:

1. Использовать рабочий доступ от компании или клиента.
2. Использовать аккаунт и оплату в поддерживаемой стране, если это твоя реальная и законная ситуация.
3. Использовать альтернативный инструмент, который официально работает в твоем регионе.
4. Работать через локальные модели, если задача допускает худшее качество.

Чего не стоит делать:

1. Покупать готовые аккаунты.
2. Покупать “доступ к ChatGPT” у неизвестных посредников.
3. Вводить API-ключи в чужие сайты.
4. Использовать поддельные данные.
5. Полагаться на VPN как на стабильный способ работы.

Такие схемы часто заканчиваются блокировкой, потерей денег или утечкой кода.

## 12. Минимальный сценарий “как сейчас”

Если нужно максимально повторить текущий режим работы:

1. Установи VS Code.
2. Установи официальное расширение Codex от OpenAI.
3. Войди через ChatGPT account или API key.
4. Открой папку проекта.
5. Напиши:

```text
Прочитай AGENTS.md и структуру проекта. Работай как coding agent: перед правками объясняй, что делаешь, меняй файлы сам, запускай проверки, не трогай чужие изменения без моей просьбы.
```

6. Дай конкретную задачу.

Например:

```text
В src/components/AboutPage.tsx улучши блок преимуществ: сохрани стиль Onixbit, проверь адаптивность и запусти доступные проверки.
```
